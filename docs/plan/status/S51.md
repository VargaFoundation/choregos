| S51-05 | S51 | ✅ | — | Knowledge accepts structured text: `.yaml`, `.yml`, `.json` and `.toml` are uploaded or synced from a source (a git source no longer skips them as `format not converted` when its `paths` name them; the default `paths` stays `*.md`, so an existing source does not start reading every configuration file).
