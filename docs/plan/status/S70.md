| S70-21 | S70 | 🟡 | — | The GitHub App is created from a manifest ([ADR 0167](../../adr/0167-the-github-app-is-created-from-a-manifest.md), proposed). The operator created the App by hand on github.com and typed four values into the deployment's Secret, and the guide's permission table had drifted from the adapters' (`statuses` and `organization_projects` missing). Now a platform administrator creates it from *Administration → GitHub App*: `POST /platform/github-app/manifest` builds the manifest from the instance's URLs and the adapters' own `APP_PERMISSIONS` and `APP_EVENTS` (public or private is a required choice, no default), the console posts it to GitHub as a form, and `GET /github/manifest/callback` checks a one-hour state signed for its own purpose and the same platform administrator's session, refuses before spending GitHub's one-time code when the deployment names an App, an App is stored or no secrets key exists, exchanges the code (`POST /app-manifests/{code}/conversions`, scriptable `FakeManifestConversion`), seals the private key, webhook secret and client secret in one envelope of `github_app_registrations` (ADR 0058, platform-only RLS), audits `github_app.create`, and the rewrap moves it with the connector secrets. One service (`services/github_app_credentials`) resolves the App for every reader, the deployment's settings first: the installations' port, the run's git token, the knowledge sources, the GitHub webhook's signature and the adapters' GitHub client (a process provider, so the key never enters a connector configuration). Guarded by `apps/api/tests/test_github_app_manifest.py` (17 tests: manifest content and URLs, required choice, rights, deployment App wins, no key spends no code, forged/expired/other person's state, refused code stores nothing, sealed not clear, every reader uses the stored App, forget, key rotation), `packages/adapters/tests/test_github_manifest_conversion.py`, `tests/procedures/test_github_app_permissions.py` (the guide's table held to the constants) and `apps/web/tests/github-app-registration.test.tsx`. Does not prove: a real round trip on github.com (the conversion is exercised against the fake and a mocked HTTP answer only; registering a real App is a manual gesture), GitHub Enterprise Server (github.com URLs only), an App per organisation, nor a replica other than the one that registered the App picking it up (the 60-second cache refresh is read in the code, not tested across processes) |
| S70-20 | S70 | ✅ | — | A change of the instance's identity provider re-links accounts in a time-boxed window ([ADR 0164](../../adr/0164-a-change-of-identity-provider-re-links-accounts-in-a-time-boxed-window.md), amends 0100).
